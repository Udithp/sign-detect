INTRODUCTION
Learnify – AI-Driven E-Learning Platform is a website designed to deliver personalized, accessible, and engaging learning experiences. In the contemporary landscape of digital education, there has been a transformative shift towards online platforms, revolutionizing the way students discover, learn, and engage with educational content. With an emphasis on diverse subjects like Python, C++, Java, HTML, CSS, JavaScript, Machine Learning, and more, Learnify offers an innovative solution to cater to the growing demand for high-quality online education. This project aims to create an intuitive and intelligent e-learning platform that adapts to individual learning styles, providing personalized feedback, interactive quizzes, assignments, and mock interview sessions. By incorporating AI-powered features like an Interview Bot and Chatbot, Learnify aims to enhance the learning journey, making quality education accessible to students globally at their convenience.

CONVENTIONAL E-LEARNING PRACTICES AND THEIR DRAWBACKS
The e-learning landscape operates through a combination of self-paced online platforms and traditional educational institutions, each presenting unique strengths and limitations to learners across the globe. Traditional classroom-based learning emphasizes face-to-face instruction, providing personalized attention and structured guidance. However, this approach often lacks flexibility in terms of time and accessibility, especially for students in remote areas or those balancing studies with work. Online education platforms have emerged to bridge this gap, offering a wide range of digital courses and resources accessible from anywhere. Despite their advantages, many platforms struggle with limited interactivity, generic course content, and inadequate real-time support. Additionally, learners may face challenges such as inconsistent content quality, lack of personalized learning paths, and difficulty in preparing for job interviews without focused assistance. Addressing these challenges is critical to creating a more inclusive and effective educational experience. Learnify is designed to enhance online learning by integrating AI-powered chatbots for instant doubt-solving, subject-wise interview preparation tools, personalized course recommendations, and real-time assessments, ultimately creating a more engaging and impactful learning environment for diverse learners.

The proposed system aims to revolutionize the e-learning experience by leveraging advanced technologies and learn-centric features.It seeks to address the existing challenges in digital education while enhancing accessibility, personalization, user engagement, and subject- skill development.

OVERVIEW OF TECHNICAL AREA
Learnify is an AI-Driven E-Learning Platform built using a modern full-stack web development approach, combining, Node.js, MongoDB Atlas, and HTML/CSS/JavaScript technologies. The backend is powered by Node.js with Express.js, providing RESTful APIs for user authentication, course management, and data handling. MongoDB Atlas is utilized as the cloud-based NoSQL database to store users, courses, enrollments, assignments and quiz data. Secure user authentication is implemented using JWT (JSON Web Tokens) and bcryptjs to protect user sessions and passwords, ensuring the platform remains secure.
On the frontend, HTML, CSS, and Vanilla JavaScript are used for building a responsive and interactive UI. The design is custom-made for flexibility and performance, without relying on pre-built frameworks like Bootstrap.Admins can manage course content, student enrollments, and other platform functionalities through a dedicated admin dashboard, while students can enroll in courses, access learning materials, and complete assignments and quizzes.
The backend of Learnify is powered by Node.js with Express.js framework, providing RESTful APIs to handle core functionalities like user authentication, course management and enrollment handling. MongoDB Atlas, a cloud-based NoSQL database, stores essential data such as user profiles, courses, enrollments. The backend also ensures secure authentication through the use of JWT (JSON Web Tokens) and bcrypts, safeguarding user sessions and passwords. It is designed to be modular and scalable, allowing for easy addition of new features without compromising the performance or security of the platform.
The platform also integrates an AI-powered Chatbot and an Interview Bot to enhance the user experience. The AI Chatbot serves as a real-time query resolution tool for students, answering questions about course content and helping with learning doubts. The Interview Bot helps students prepare for technical interviews by offering subject-specific questions and providing instant feedback on their answers.
The Learnify platform uses Node.js as the HTTP server with Express.js to handle incoming API requests, server static content, and process dynamic content. This single-stack solution simplifies deployment and management, as Node.js handles both client and server-side logic, including serving files and interacting with database. The platform is designed to be scalable and secure and modular, ensuring smooth performance even as the user base and content grow.

});
const raw = await response.text(); let data;
try {
data = JSON.parse(raw);

alert("Server didn't return valid JSON."); return;
}
if (!response.ok) throw new Error(data.message); alert(data.message);
// Save enrolled course
let enrolledCourses = JSON.parse(localStorage.getItem("enrolledCourses")) || [];
if (!enrolledCourses.includes(courseName)) { enrolledCourses.push(courseName); localStorage.setItem("enrolledCourses", JSON.stringify(enrolledCourses));

window.location.href = coursePage;

const slider = document.getElementById('slider'); const prevBtn = document.getElementById('prevBtn'); const nextBtn = document.getElementById('nextBtn');
const courseBoxes = document.querySelectorAll('.course-box'); const boxWidth = 305;
let currentIndex = 0; let maxIndex;
let enrolledCourses = new Set(); let currentCourse = '';
const modal = document.getElementById('enrollModal'); const modalTitle = document.getElementById('modalTitle'); const coursePageMap = {
"Introduction to Programming Languages": "prog.html", "Data Structures and Algorithms": "DSA.html", "Machine Learning": "ML.html",
"Artificial Intelligence": "AI.html", "Operating Systems": "OS.html", "Computer Networks": "CN.html"
};
function updateSlider() {
slider.style.transform = `translateX(-${currentIndex * boxWidth}px)`; prevBtn.disabled = currentIndex === 0;
nextBtn.disabled = currentIndex >= maxIndex;
}
function calculateMaxIndex() {
const wrapperWidth = document.querySelector('.slider-wrapper').offsetWidth; const itemsPerView = Math.floor(wrapperWidth / boxWidth);
maxIndex = Math.max(courseBoxes.length - itemsPerView, 0); currentIndex = Math.min(currentIndex, maxIndex); updateSlider();
prevBtn.style.display = courseBoxes.length <= itemsPerView ? "none" : "inline-block"; nextBtn.style.display = courseBoxes.length <= itemsPerView ? "none" : "inline-block";
}
nextBtn.addEventListener('click', () => { if (currentIndex < maxIndex) { currentIndex++; updateSlider(); } });
prevBtn.addEventListener('click', () => { if (currentIndex > 0) { currentIndex--; updateSlider(); }
});
function showModal(courseName) { currentCourse = courseName;
modalTitle.textContent = `Do you want to enroll in ${courseName}?`; modal.style.display = 'flex'; document.getElementById('modalUsername').value = ''; document.getElementById('modalPassword').value = '';
}

}
async function submitEnrollment() {

alert('Please fill in both username and password.'); return;
}
try {
const loginResponse = await fetch('http://localhost:3000/user/login', { method: 'POST',
headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ username, password })
});
const loginData = await loginResponse.json();
if (!loginResponse.ok) throw new Error(loginData.message); localStorage.setItem('username', username);
await fetchEnrollments(username); disableEnrolledButtons();

});
const enrollData = await enrollResponse.json();
if (!enrollResponse.ok) throw new Error(enrollData.message); alert(enrollData.message);
closeModal(); enrolledCourses.add(currentCourse); disableEnrolledButtons();

setTimeout(() => { window.location.href = redirectPage;

alert("No page found for: " + currentCourse);

} catch (err) {
alert("❌ " + err.message);
}
}

function shuffleArray(array) {
for (let i = array.length - 1; i > 0; i--) {
const j= Math.floor(Math.random() * (i+ 1)); [array[i], array[j]] = [array[j], array[i]];
}
return array;
}
function displayQuestion() {
if (currentQuestionIndex < questions.length) {

function processAnswer() {
const answer = userInput.value.trim(); if (answer) {
addUserMessage(answer); userInput.value = '';
// Check if user doesn't know the answer
const notSurePattern = /(idk|i don('|’)t know|not sure|no idea|don('|’)t know)/i; if (notSurePattern.test(answer)) {
const correctAnswer = questions[currentQuestionIndex].answer;
addBotMessage(`<span class="unknown">You indicated you don't know the answer.</span>`);
addBotMessage(`<div class="correct-answer">Correct answer:
${correctAnswer}</div>`);
userAnswers.push("IDK"); correctAnswers.push(correctAnswer); answerStatus.push("unknown");
score += 0; // No points for not knowing
} else {
// Evaluate the answer
const isCorrect = evaluateAnswer(answer, questions[currentQuestionIndex]); const correctAnswer = questions[currentQuestionIndex].answer;
if (isCorrect) {
addBotMessage(`<span class="feedback-correct">Correct! Welldone!</span>`); userAnswers.push(answer);
correctAnswers.push(correctAnswer); answerStatus.push("correct");
score += 1;
} else {
addBotMessage(`<span class="feedback-incorrect">Not quite right.</span>`); addBotMessage(`<div class="correct-answer">Correct answer:
${correctAnswer}</div>`);
userAnswers.push(answer); correctAnswers.push(correctAnswer);
answerStatus.push("wrong");
score += 0; // No points for wrong answers
}
}
currentQuestionIndex++; setTimeout(displayQuestion, 1000);
}
}
function evaluateAnswer(userAnswer, questionObj) {
// Simple evaluation - check if answer contains enough keywords const keywords = questionObj.keywords;
const lowerAnswer = userAnswer.toLowerCase(); let matchedKeywords = 0;
for (const keyword of keywords) {
if (lowerAnswer.includes(keyword.toLowerCase())) { matchedKeywords++;
}
}
// Consider answer correct if it matches at least half the keywords return matchedKeywords >= Math.floor(keywords.length / 2);
}

ABSTRACT
AI Driven E-Learning platform is developed to enhance online education by integrating intelligent features into a web- based learning environment. The platform is built using HTML, CSS, JavaScript, Node.js, and MongoDB, and offers core functionalities such as secure login for students and admins, course enrollment, and assignment uploads. The platform features a built-in Interview Bot that conducts subject-specific mock interviews. After each session, it evaluates the user's performance, displays a preparedness score in percentage, and provides the correct answer with a short explanation for any incorrect responses. Additionally, an AI-powered Chatbot is implemented directly on the website to assist students by answering subject-related queries in real time, thus making the learning process more interactive and accessible. The system is designed for simplicity and user engagement, without the need for complex backend module structures. Based on analysis and user feedback, the platform promotes active learning, encourages self-assessment, and enhances the overall user experience. This implementation demonstrates how AI-driven components, when effectively embedded in educational platforms, can significantly support personalized and responsive learning, offering a scalable solution for modern digital education.
Keywords: E-Learning, Interview Bot, Chatbot, AI in Education, Web Development and Student Evaluation.
INTRODUCTION
In recent years, the demand for flexible and accessible education has led to the rapid growth of e-learning platforms. With advancements in web technologies and artificial intelligence, digital learning environments have evolved from static course delivery systems into intelligent, interactive platforms. AI Driven E-Learning platform is an innovative approach that combines core learning functionalities with smart features to support students beyond traditional content delivery. The platform integrates tools such as an Interview Bot and a Chatbot to create a more engaging and personalized learning experience. The Interview Bot helps students practice subject-specific questions in a mock interview format, assess their preparation level, and learn from their mistakes through immediate feedback and explanations. Similarly, the Chatbot assists students by answering academic queries in real time, simulating a 24/7 virtual tutor. While many existing platforms offer video lessons and quizzes, few integrate AI-based tools that actively support self-assessment and doubt clarification. This project aims to bridge that gap by implementing a lightweight, user-friendly e-learning solution enhanced with intelligent support systems, aligning with current trends in educational technology and learner-centered design.
METHODOLOGY
Development of AI Driven E-Learning Platform
The AI Driven E-Learning Platform was developed using HTML, CSS, JavaScript, Node.js, and MongoDB. The core goal was to build a responsive and intelligent learning environment that functions without heavy module dependency. Essential features include user authentication, course enrollment, and assignment upload functionalities.
Design and Implementation of Interview Bot and Chatbot
The Interview Bot was designed to test subject knowledge through a quiz-like interface, followed by instant evaluation and explanation for incorrect answers. The Chatbot, using basic AI scripting, assists users with academic queries, enhancing interactive learning and support.
Integration of Student Authentication and Course Enrollment
Secure login using JWT and bcryptjs was implemented to authenticate students and admins. Students can enroll in courses, and their details are stored in MongoDB. Upon successful enrollment, students are redirected to related resources like YouTube course content.

RESULTS AND DISCUSSION
The proposed E-Learning Platform was developed using HTML, CSS, JavaScript for the frontend, and Node.js with MongoDB (using mongosh) for the backend. The platform includes features such as student signup/login, admin login, course enrollment, and video redirection. Below are the key outcomes and discussion points:
User Signup and Login:
The signup and login functionality was implemented using JWT for secure authentication. Student credentials are stored in the MongoDB database, and users are redirected upon successful login. Admin login is restricted to authorized users only, ensuring secure access to the admin panel.
Course Enrollment:
Students can enroll in courses by clicking an "Enroll" button. A confirmation prompt ensures the student wishes to proceed. Upon confirmation, the enrollment is stored in the MongoDB database, capturing the student's name, email, course name, and video URL. Students are immediately redirected to the course video (e.g., on YouTube), creating a smooth transition from enrollment to learning.
Admin Dashboard:
The admin panel displays a list of all enrolled students along with their names and email addresses. It also shows which courses have been selected by which students. This functionality is powered by MongoDB queries and displays real- time enrollment information on the frontend. Access to this dashboard is protected and available only to logged-in admins.
Chatbot and Interview Bot Integration:
An AI-powered chatbot is available to assist students with general learning queries, enhancing the user experience. Additionally, the platform includes an interview bot that quizzes students with subject-specific questions (e.g., HTML, CSS, JavaScript, Python, etc.), checks responses, and provides feedback on performance. This feature aims to simulate real-world interview preparation and improve learning outcomes.
Discussions
The project achieves a minimal yet practical e-learning system that integrates key educational tools. Although advanced features such as analytics, student progress tracking, and database-based quizzes are not implemented in this version, the foundation laid by the current modules is reliable and scalable. The inclusion of AI components like the chatbot and interview bot distinguishes the platform by offering interactive learning support. The decision to use mongosh for MongoDB interactions keeps the system lightweight and easy to maintain for academic and prototype purposes.
CONCLUSION
The developed E-Learning Platform successfully fulfills the core objective of providing a user-friendly and functional web-based learning environment. The project integrates essential features such as student registration and login, secure admin access, course enrollment, and immediate redirection to relevant video content. The use of Node.js for the backend and MongoDB via mongosh for data storage ensures lightweight and efficient server-side operations. The platform’s design prioritizes simplicity, making it easy to navigate for both students and administrators. Course enrollments are reliably stored in the database, with persistent data across server restarts, and the admin panel offers clear visibility into student activity. The implemented file upload feature allows the addition of assignments and materials, supporting basic resource distribution without complex infrastructure.
